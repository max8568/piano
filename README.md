# 鋼琴五線譜

開啟時先播開場動畫：第一人稱走進有動物的叢林，五線譜從草叢中間撥開煙霧、由小到大浮現，停在這裡顯示「點一下開始」；點下去啟動聲音，鍵盤與五線譜滑進畫面。
在 iPad 上按琴鍵，就會在上方的大譜表依序寫出音符。音符長短看按住多久：不到 0.2 秒是八分音符（半拍）、0.2～0.5 秒是四分音符（一拍）、0.5～1.2 秒是二分音符（兩拍）、更久是全音符（四拍）；按住時譜上的音符會跟著變長，看到想要的長度就放開。音符不會超過小節線（小節只剩半拍時再久也是八分音符）。
記譜依照一般 4/4 的寫法：同一拍裡的八分音符用符槓連起來；不在拍點上開始的音符拆成用連結線連起來的幾個音符，讓每一拍與小節中間的第 3 拍都看得出來（例如反拍上的四分音符寫成八分⁀八分）。
長按譜上的音符，它會變藍並跟著手指移動；往上拉到變紅再放開，就能刪掉那個音符。
右上角的「清除」會刪掉所有音符：按一下變成「確定清除？」，3 秒內再按一下才會清除。
右上角的「測驗」進入認譜測驗。先在鍵盤上拖曳選範圍（從按下的鍵拖到放開的鍵，範圍內會出題的鍵變藍，選範圍時按鍵不發聲；勾「含黑鍵」時黑鍵也出題，隨機寫成升或降記號；範圍會記住），按「開始」後譜上出一個範圍內的音，按對應的琴鍵作答。答對的音變綠留在譜上，下一題接在右邊；按錯時按錯的鍵和題目閃紅，不換題、也不提示答案，要按到對為止。右上角顯示「一次就答對的題數／完成的題數」，按「範圍」可以回去改範圍，按「結束」回到原本的樂譜（測驗不會動到寫好的音符）。

## 本機開發

不需要建置工具。因為使用 ES modules，需要透過網頁伺服器開啟：

```sh
npm run serve   # 啟動後會印出本機與 iPad 用的網址
npm test        # 單元測試（Node 內建 test runner）
```

在 iPad 上測試不用推上 GitHub Pages：Mac 與 iPad 連同一個 Wi-Fi，`npm run serve` 後用 iPad 的 Safari 開啟印出的 `http://192.168.x.x:8000`。
伺服器不讓瀏覽器快取，改完檔案在 iPad 重新整理就是新版。
用區網 IP 開啟時沒有 Service Worker（瀏覽器只在 https 或 localhost 提供），離線功能要在 GitHub Pages 上測。

## 安裝到 iPad（PWA）

用 Safari 開啟網址 → 分享 →「加入主畫面」。開過一次之後就能離線使用（含聲音）。

更新：開啟 App 時會檢查有沒有新版，新版下載並核對完就接手；譜上還沒有音符會自動重新載入成新版，否則下次開啟就是新版。
新增檔案時要加進 `sw.js` 的 `PRECACHE`（`npm test` 會檢查有沒有漏）。
每次發佈前執行 `npm run release`：`version.js` 與 `sw.js` 的 `VERSION` 一起加一，並重算 `sw.js` 裡每個程式檔的指紋（`npm test` 會檢查版本一致、指紋最新）。
新版的 Service Worker 會核對下載到的每個檔案都是這一版的才接手，不會出現新舊檔案混雜；畫面左上角顯示的版本號就是實際在跑的版本。
